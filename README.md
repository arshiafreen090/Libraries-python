# Python Libraries
## **Python Data Science Toolkit**

This repository contains a collection of Jupyter Notebooks exploring the core libraries of the Python Data Science ecosystem: **NumPy, Pandas, Matplotlib, and Seaborn**.

## 1. NumPy (Numerical Python)
- Fundamentals of N-dimensional arrays (`ndarray`).
- Vectorized operations and broadcasting for high-performance computing.
- Mathematical functions, linear algebra, and random number generation.

## 2. Pandas (Data Analysis)
- Working with `Series` and `DataFrame` objects.
- Data cleaning, handling missing values, and data transformation.
- Grouping, pivoting, and merging datasets (using `gapminder`, `tips`, and `titanic` datasets).

## 3. Matplotlib (Static Visualization)
- Low-level control over figures and axes.
- Creating basic plots: line, scatter, bar, and histograms.
- Customizing labels, titles, legends, and figure sizes.

## 4. Seaborn (Statistical Visualization)
- **Relational Plots:** Using `scatterplot()`, `lineplot()`, and `relplot()` for bivariate analysis.
- **Distribution Plots:** Analyzing data density with `histplot()`, `kdeplot()`, `displot()`, and `rugplot()`.
- **Matrix Plots:** Visualizing correlations and heatmaps using `heatmap()` and `clustermap()`.
- **Categorical Plots:** Visualizing categorical data with `boxplot()`, `violinplot()`, `barplot()`, and `countplot()`.
- **Multi-plot Grids:** Using `faceting` (col/row) via Figure-level functions like `relplot()` and `catplot()`.

## Datasets Used
- **Tips:** Restaurant tipping data for categorical and relational analysis.
- **Titanic:** Passenger data for distribution and survival analysis.
- **Gapminder:** Global development data for time-series and faceted scatter plots.
- **Iris:** Flower measurements for matrix clustering.
> **Note:** You can download the complete dataset here: **[dataset_colab.zip](./dataset_colab.zip)**
